# Learn to Code

A personal repository dedicated to tracking logic-building exercises, core programming concepts, data structures, and practical coding notes as part of my journey as an IT student and aspiring software engineer.

## 🛠️ Tech Stack & Focus

- **Primary Language:** JavaScript (ES6+)
- **Core Focus:** 
  - Algorithmic problem-solving and data structures
  - Clean, modular code implementation
  - Core programming fundamentals and logic building

## 📂 Repository Structure

### 1. `logic-building/`
Structured step-by-step logic-building exercises and problem sets:
* **Phase 1: Conditional Thinking**
* **Phase 2: Looping & Patterns**
* **Phase 3: Recursion**
* **Phase 4: Basic Arrays**
* **Phase 5: Strings**
* **Phase 6: Mixed Logical Challenges**

> **Credits & Acknowledgments:** The curriculum and problem structure implemented in this folder are adapted from the official materials by **Nishchal Muradia** ([CodeWithNishchal](https://www.youtube.com/@CodeWithNishchal) | [LinkedIn](https://www.linkedin.com/in/nishchal-muradia/)).
